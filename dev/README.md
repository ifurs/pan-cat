# dev/

Prototypes and demos kept for reference. They are not part of the game and are not published once
GitHub Pages deploys from the `pages` workflow (which ships only `index.html` plus license and credit files).

- `original.html`: the first prototype.
- `cat-variants.html` (+ `chibi_rows.js`, `cat-variants.png`): cat sprite variants. Open it from this folder; it loads `chibi_rows.js` next to it.
- `cat-sounds-demo.mp3`: a listening demo of the cat sounds.
