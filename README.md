# Пиріжок проти гравітації 🐈

Маленька піксельна гра для телефона: рудий кіт Пиріжок скидає речі зі столу, поки господар не дивиться.

**Грати:** https://ifurs.github.io/pan-cat/

- Тапай по екрану, і кіт штовхає речі.
- Господар обертається? Замри.
- 💕 Позуй, коли він дивиться, і він розтане: фотосесія з очками ×2.
- Господар має різні настрої, а складність підлаштовується під гравця сама.
- За рибки 🐟 у гардеробі можна купити шапки, бантики й вишиванку.

Уся гра — це один файл `index.html` без залежностей, звуки й шрифти вбудовані в нього.
Після зміни звуків чи шрифтів запусти `audio/embed.py` або `fonts/embed_fonts.py`.
